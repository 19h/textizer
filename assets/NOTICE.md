# Embedded font provenance

The `.bin` files contain the printable ASCII glyph subset rasterized from the
reference project's Pillow fonts. The data layout and SHA-256 hashes of the
source `.pil` / `.pbm` files and derived arrays are in `fonts.json`.

| Font | X.Org source distribution | Redistributed notice |
|---|---|---|
| 6x13, 9x18 | [font-misc-misc 1.1.3](https://www.x.org/releases/individual/font/font-misc-misc-1.1.3.tar.xz) | [LICENSE-misc.txt](LICENSE-misc.txt) |
| 8x16 | [font-sony-misc 1.0.4](https://www.x.org/releases/individual/font/font-sony-misc-1.0.4.tar.xz) | [LICENSE-sony.txt](LICENSE-sony.txt) |
| clR5x10 | [font-schumacher-misc 1.1.3](https://www.x.org/releases/individual/font/font-schumacher-misc-1.1.3.tar.xz) | [LICENSE-schumacher.txt](LICENSE-schumacher.txt) |

Notices are copied from the corresponding upstream `COPYING` files. Binary
rasters are generated by `scripts/import_fonts.py`; no host fonts are used by
the Rust or WebAssembly renderer. Source hash identity to the local reference
is established; identity to every historical upstream distribution is not claimed.
